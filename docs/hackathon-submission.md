**MERIDIAN — NEAR Ecosystem Intelligence**

## Project description

MERIDIAN is a public, read-only intelligence dashboard designed to make the state of the NEAR ecosystem easier to inspect and independently verify. It brings three connected capabilities into one working product:

1. **NEAR Network Monitor:** chain TVL and historical observations from DefiLlama; daily transactions and address activity from NearBlocks when the provider returns recognised completed-day data; and NEAR stablecoin supply from DefiLlama.
2. **Ecosystem Development Tracker:** discovers a limited set of NEAR-related public GitHub repositories, inspects README evidence, and displays repository metadata, latest push dates and recent commit messages.
3. **NEAR Investment Thesis:** produces a deterministic scorecard from observed percentage changes. Positive, negative, stable and inconclusive signals are labelled using explicit thresholds. The dashboard shows the calculation method, retrieval time, source links and data-quality warnings.

The public dashboard requires no wallet connection, account, payment or model API credit. Its public API gathers data from the underlying sources and caches the snapshot for five minutes. The refresh control bypasses the cache and requests a new snapshot. The thesis is calculated from the returned source metrics, not generated by a language model.

The product is built with Next.js and FastAPI and deployed on Railway. It uses public DefiLlama, NearBlocks and GitHub endpoints. Missing or unrecognised data is shown as unavailable rather than replaced with invented values.

## Suggested judge demo

1. Open the live dashboard. Confirm that it loads without wallet sign-in.
2. Inspect chain TVL and historical 7-day and 30-day changes. Review the 30-observation chart and freshness note.
3. Check latest completed daily transactions and active/unique address metrics. Note that current incomplete UTC-day data is excluded.
4. Inspect NEAR stablecoin supply and its measurement limitations.
5. Review the developer tracker. Open one of the listed GitHub repositories and verify its latest commit evidence.
6. Inspect the investment thesis signal breakdown. Explain the transparent thresholds: above +1% is positive, below -1% is negative, and between those values is stable. Missing comparisons remain inconclusive.
7. Open the source registry and quality warnings. Explain why TVL is not a user count and GitHub activity does not prove production usage.
8. Press Refresh data to fetch a new source snapshot.

## Current limitations to disclose

- NearBlocks daily transaction or address metrics may be unavailable if its public endpoint does not return a recognised response.
- GitHub discovery is limited and incomplete. Repository descriptions, README claims, stars, forks, pushes and commit messages do not prove a deployed product, active users, revenue or on-chain usage.
- DefiLlama TVL and stablecoin supply are separate measures; neither alone establishes user adoption, fees or economic value.
- The thesis scorecard is a transparent descriptive heuristic, not investment advice or a prediction.
- Data providers have different coverage windows and update schedules. The dashboard displays retrieval timestamps and warnings but does not make the sources identical.
- The older private research-order workspace remains in the repository but is separate from the public product. NEAR AI Cloud/Gemini inference, customer payments, settlement, contributor payouts, wallet custody and mainnet execution are not required for the public dashboard and are not represented as active features.
